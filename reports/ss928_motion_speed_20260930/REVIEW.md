## 速度改动及边界

上一轮天气主卷积乘加减少约 67%，完整图 GPU 没有提速；上一轮新图没有 NPU 实测，因此此前没有可确认的板端速度收益。用户 v0.12 报告的纯 NPU 均值约 38.9～63.4 ms，仍高于目标；报告没有纯 NPU P95。

本轮修改输出铺排：在小网格上先转换为无符号 8 位整数，再通过形状重排、轴交换和索引复制恢复完整输出，替换浮点反卷积铺排。三倍输出仍为原网格最近邻复制，没有新增三倍学习细节。主体、参考路径和权重保持一致，输入仍为九帧，输出为 `1×1×3072×3840`。

同类型输出的公平比较如下，均为完整模型前向，输入已驻留 GPU；主计算 FP16，最终输出无符号 8 位整数，RTX 5090 的 GPU 1，30 次预热、300 次计时，关闭 TF32 与 CUDA 图，使用 `torch.compile(mode='default')` 编译。时间包括模型图内输出铺排，不包括文件读取及主机传输；编译后的 GPU 收益不代表未编译执行或 NPU 的收益。

| 模型 | 原浮点铺排后转字节：均值/P95 ms | 小网格先转字节再铺排：均值/P95 ms | 均值下降 |
|---|---:|---:|---:|
| 半网格九帧 | 0.342207 / 0.349666 | 0.297176 / 0.299246 | 13.2% |
| 四分之一网格九帧 | 0.347614 / 0.357835 | 0.289480 / 0.294248 | 16.7% |

四天气各 120 帧，在相同 FP16 后端，先转字节铺排与原完整浮点铺排后采用相同截断转换，完整输出逐像素相等，共 480 帧。四张导出图检查通过，并在 ONNX Runtime 的 CPU 后端运行末帧：相对于 PyTorch GPU 的字节输出平均差约 0.02～0.05 灰度，最大 1 灰度，涉及 FP16 后端数值差异。模型文件下载后的 SHA-256 与服务器记录一致。

这里的字节转换采用截断；与四舍五入保存图像最多可差 1 灰度。SDK 的实际转换行为，以及字节索引复制、轴交换是否支持、是否回退、耗时如何，均待 SS928 验证。GPU 提速比例不能换算成 NPU 收益。本轮仅提供四天气整数输出候选，没有将其推广成七类已通过方案。

## 拖影定位及代价

固定权重，仅将主体归一化后的九个历史通道替换为末帧重复值，参考与因果 RAW 校正保持原样。这是诊断干预，模型输入语义发生变化，不能称为等价部署修改或完整单帧系统。

对 GT 中亮、暗目标分别提取候选区域，在历史八帧目标出现过、当前目标附近已排除的区域计算同极性残留；同时检查当前位置、对比与静态区域变化。

| 场景 | 原半网格九帧：历史残留灰度 / 位置误差像素 | 半网格末帧替代 | 原半网格→末帧替代：静态残差变化灰度 |
|---|---:|---:|---:|
| 轻天气 | 6.54 / 5.03 | 5.15 / 3.50 | 0.93→1.34 |
| 中天气 | 6.89 / 3.93 | 6.04 / 2.82 | 0.92→1.32 |
| 重天气 | 7.66 / 5.52 | 6.20 / 3.44 | 1.52→2.31 |

这些控制结果支持主体历史融合参与目标拖影和弱化；简单移除历史会增加静态区域残差波动。该统计包含噪声及其他变化，不能单独等同于噪声强度。原四分之一九帧相较原半网格有部分改善，但当前目标对比与 GT 的比值仍约 0.56、0.70、0.57，目标仍偏弱。

另核对 RAW 与 GT 的时间关系：三场景当前 RAW 都在同帧相关性最高。轻天气原半网格在使用较晚的模型帧与当前 GT 比较时，相关性从 0.635 增至 0.696，最佳偏移 +5 帧；末帧替代及原四分之一九帧最佳偏移为 0。重天气偏移收益较弱，中天气最佳偏移为 0。该结果是道路目标区域的聚合诊断，不能解释成每个目标固定延迟五帧，不能换算毫秒。训练和评估没有人为平移 GT。

指标局限：目标区域由 GT 阈值自动提取，包含亮、暗区域，非人工车辆标注；每种方法独立扣除 120 帧中值背景及每帧道路整体漂移，仅用于离线分析，模型没有使用未来帧。位置误差是局部带符号前景重心的距离；不能代表检测器精度或每辆车的人工标注误差。C32 有效区域不覆盖此道路，因此不纳入道路拖影统计。

## 新训练原型的结果

尝试两种历史限制：一组在四分之一网格按当前帧差异限制历史输入；另一组在原网格依据局部平均差异抑制历史融合。保留当前帧的 16 个像素相位及参考分支，训练了宽度 8/16 的模型。训练使用既有训练缓存、固定种子 930，采样兼顾均匀覆盖与运动区域，增加目标及相邻帧误差约束。权重由验证集选择；研发过程中反复观察测试集，这些测试结果不属于一次性盲测。

低网格原型的全量轻/中/重天气 PSNR 为 32.225 / 31.402 / 29.752 dB；原网格原型为 32.302 / 31.469 / 29.914 dB。两者均未兼顾全图质量与目标响应。原网格版本降低静态残差波动，但相较已有四分之一九帧，三场景的历史残留及目标位置误差都更差，且完整 GPU 模型更慢，因此不采用。

低网格原型的历史特征幅度约束只作用于输入特征，不保证最终输出残留有同样上界。原网格原型的阈值以归一化输入乘 255 为单位，尚未通过训练噪声标定，不能当成可靠运动判别器。当前失败原因尚未严格拆分，不归结为单一门限或容量问题。

记录：[低网格全量评估](results/coarse_evaluation.json)、[原网格全量评估](results/native_evaluation.json)、[低网格目标指标](results/reliable_signed_target_summary.json)、[原网格目标指标](results/native_signed_target_summary.json)、[六份训练配置与缓存校验值](results/training)。这些早期目标分析 JSON 中 `weights_changed=false` 表示分析程序不修改权重；两种原型确实经过新训练，不能据此理解为与旧模型同权重。分析源码已将字段改成 `analysis_modifies_weights` 以明确含义。

服务器所有实验及权重位于 `/data/zhangbenzhuang/huawei_sr/runs/SS928-MOTION-SPEED-20260930`；原型分别为 `reliable_light/heavy`、`reliable16_light/heavy`、`native_reliable_light/heavy`。原权重和训练缓存均未覆盖。训练入口：[train_reliable.py](runtime/train_reliable.py)。实验脚本依赖上一轮运行目录中的基础模型与数据配置，并非独立安装包。

## 本轮审查范围与下一步

可审查的速度改动为整数输出结构及四天气完整图；本轮两个新历史模型仅保留实验。待用户明确批准后再整理板测交付，核实 SDK 全部算子在 NPU 执行、转换数值一致、九个不同历史输入、纯 NPU 均值和 P95，以及连续目标画质。仅凭平均耗时或重复同一 RAW 的九帧输入不足以完成验收。

拖影方向后续需要让历史可靠性判断保持小目标空间信息，并同时约束目标位置、残留、静态噪声与建筑细节；近帧融合、训练目标采样或运动对齐尚未在本轮实现，不能算作已获得的改进。
