# SS928 四组提速模型部署交付

本轮供部署测试：四组同结构、不同训练权重，16通道、2主干块、4倍输入打包、1×1末端卷积，净3倍输出。RAW整图参考已包含在图内，推理不需要GT；中间RAW辅助头已移除。

先读 [部署步骤](DEPLOYMENT.md)，再读 [归一化与ONNX要求](NORMALIZATION_ONNX.md)。接手人员读 [交接文档](HANDOFF.md)。目录见 [文件说明](DIRECTORY.md)，所有文件及模型校验值见 `MANIFEST.json`、`MODEL_MANIFEST.json`。

|模型目录|场景|选定步数|理论换算SS928耗时|
|---|---|---:|---:|
|`models/day/`|白天|10000|15.22 ms|
|`models/light_medium/`|轻度、中度天气|8000|15.03 ms|
|`models/heavy/`|重度天气、C32|12000|15.48 ms|
|`models/night/`|普通、特殊夜间|10000|15.12 ms|

**上述耗时为5090实测按历史比例换算；本轮ONNX尚未在SS928转换或实测。目标是仅模型推理≤16.7ms，用户原部署为41ms。**

建议先用 `heavy` 检查转换、速度及画质，再测其他组。四组结构相同，但权重和标定输入不同，转换与误差验证应逐组完成。当前画质尚未验收：白天退化明显；其他场景的整图PSNR较接近，但裁块结构相似度下降；特殊夜间仍低于保留的原裁块训练版。完整依据见 [跨场景结果](reports/cross_scene/RESULTS.md) 和 [轻中度结果](reports/light_medium/RESULTS.md)。后者为历史报告，包含本包未选用的其他结构。

C32、特殊夜间此前使用空间留出区域，缺少独立整帧质量验证；本包提供的整帧样例及初始标定样例覆盖另外五类。不得把区域指标当作整帧部署结果。

旧S03部署包仍在仓库根目录。不要使用旧包的模型预期输出来核验新模型。当前目录可独立打包，原始图像、GT和演示视频未纳入；少量RAW二进制样例用于复现输入及初步标定。
