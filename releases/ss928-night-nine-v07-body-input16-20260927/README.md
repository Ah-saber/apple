# 九帧模型主体压缩、量化校准与16槽输入实验

## 交付状态与目标

目标仍为 SS928 完整模型推理 ≤16.7 ms；保留九帧去噪、亮度/局部对比度、弱目标及完整输出。新候选没有 SS928 实测，不能宣称达到目标。此次继续了训练、等价重排、权重量化校准、完整 GPU 测速和画质验证。父提交 `b5802f9ace1b7574db947a1e41f25909fccc3ed9` 与所有旧交付均保留。

输入九个真实帧1024×1280，参考缩图64×64，完整输出3072×3840。输入文件读取、表示准备及传输不计入模型时间；统计计算、参考分支及完整输出展开保留在模型。NPU输入/输出格式转换仍属于完整模型考核。

## 实际改动

1. 原四层16通道3×3主体，训练三层、两层、一层替代网络。三轮主体训练共168000步；参考分支另32000步，共18个独立训练/续训结果、200000次实际优化器更新。一层和部分初始化方案退化，保留记录并排除。
2. 对选定的三层/两层主体，在训练特征上搜索相邻卷积间正的二次幂通道缩放。同步缩放前层权重/偏置与后层输入权重，实数函数保持不变，新增推理算子数为零。四个校准结果完整保存。半精度系数必须可精确表示；实际权重双精度对照见证据。
3. 输入改为九真实帧＋七零槽，半精度声明 `[1,1024,1280,16]` 或 `[1,1,1024,1280,16]`，模型内恢复卷积排列，统计核从9补零到16输入槽。尝试设备通道对齐；五维接口及格式支持须由SDK确认。
4. 保留上轮32通道正负ReLU统计、单次固定输出反卷积与完整半精度输出。新主体及输入布局分别与其组合，提供独立对照。
5. 另实际训练16通道简化参考分支、测试12→16补零等价参考分支和Head/主体首层融合。简化参考画质退化、补零参考普通GPU变慢、首层融合GPU变慢，均排除主候选。代码和失败证据保留。

## 完整 GPU 实测

RTX5090，test环境PyTorch2.7.0+cu128，编译后执行；关闭TF32和CUDA图，30次预热、3×200次逐次事件同步。以下为正序与逆序两轮均值范围，输入表示准备在区间外。

| 完整模型候选 | 普通 ms | 特殊夜间 ms | 与同轮父版比较 |
| --- | ---: | ---: | --- |
| 父版，Half九帧输入、Float32完整输出 | 0.307964～0.315853 | 0.312407～0.316949 | 对照 |
| 三层主体＋通道校准，同父版接口 | 0.296624～0.297263 | 0.294919～0.300676 | 快约3.5%～6.1% / 5.1%～5.6% |
| 两层主体＋通道校准，同父版接口 | 0.277415～0.279426 | 0.273624～0.275726 | 快约9.3%～12.2% / 11.7%～13.7% |
| 16槽四维输入＋固定完整Half输出 | 0.533082～0.552901 | 0.528195～0.543034 | 接口、统计和输出实现不同 |
| 16槽五维输入＋固定完整Half输出 | 0.527141～0.531760 | 0.523249～0.532751 | SDK接口支持未知 |
| 16槽四维输入＋三层主体＋固定完整Half输出 | 0.509985～0.525812 | 0.512349～0.520817 | NPU收益未知 |

另一次固定输出同接口对照：旧四层NPU候选GPU普通/特殊0.563069/0.564531 ms；三层0.551482/0.546117，两层0.532448/0.527081，五维16槽＋三层0.536210/0.535166。这些均为服务器GPU，`_npu`后缀只表明用于NPU编译尝试，未取得实板成绩。不同接口计时不得混为同一对照。GPU加速比例不能换算SS928收益。

- `source_onnx/`：36个源码图，两场景×9方案×整图/64×96对照。全部通过ONNX结构检查；尚无SDK编译兼容性结论。
- 顶层20个主体权重、2个失败参考分支权重、`frozen_models/`4个父版权重；失败参考目录还保存原始副本。
- `runtime/`：完整运行与候选加载代码，`tools/`：保留原设备图其余部分的主体移植工具及实际权重测试。
- `*_final_quality.json`、`*_full_npu_quality.json`：完整180帧源码数据；`*_final_speed*.json`、`*_full_npu_speed.json`含全部逐次计时。
- `*_training.json`、`*_quantsearch.json`和训练日志：初始化、训练、校准证据；`reference_experiments/`保留参考分支全部失败/等价尝试。
- `MEASURED_SUMMARY.json`：可读指标汇总；`MANIFEST.json`：本交付逐文件大小与SHA256。

从apple完整检出本分支，保留同级 `ss928-night-nine-system-speed-20260926` 依赖；若使用稀疏检出，必须包含该目录。运行加载器可设置 `RAWIR_SYSTEM_RELEASE_DIR` 为其绝对路径，`sys.path`加入本交付runtime目录，然后 `load_input(scene,case,本交付路径)`。训练/评估脚本为已执行服务器快照，固定根目录 `/data/zhangbenzhuang/huawei_sr/`；迁移时修改路径并保留原快照。完整实验输入数据不在此小模型交付中，沿用服务器训练ROI和180帧测试数据。训练未使用GT梯度，固定训练步；测试用于方案判断，非盲测。最后4个训练记录留出，训练诊断仅监测其中前两对，未冒称完整留出评估。
