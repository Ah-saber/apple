# 16通道参考分支压缩

父版本b5802f9，三层3×3卷积、两次ReLU、两次空间均值及加法；保持64×64参考输入、16×64×64投影特征与原整图插值。新分支替换整个多尺度参考编码和投影。

已有8通道两层参考压缩曾有明显质量下降。本次16通道三层，加入中间全局均值，以及通过冻结Tail/输出监督的相邻帧灰度损失。只用训练记录的完整参考缩图与训练ROI主体特征；两场景固定16000步，种子2785，测试/GT不用于训练或选步。训练损失的参考裁剪用与整图插值相同坐标的grid_sample，部署图没有grid_sample。

需完整普通60帧/夜间120帧质量和弱目标检查、GPU实测；源ONNX任务数减少不等于NPU已提速。原83任务/5.66ms与特殊26任务/4.96ms仅用于确定改动对象，新SDK任务与耗时仍未知。
