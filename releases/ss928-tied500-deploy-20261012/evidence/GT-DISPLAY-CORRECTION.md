# GT显示修正

七景原GT均为完整1024×1280图像。此前视频错误地把评估ROI当作GT可显示范围，并将区域外涂灰。重天气C32和特殊夜景的右侧192像素是空间测试区域，不是仅有的GT数据。独立CPU显示修正已恢复全部GT，当前gt_pairs/REVIEW.html及同名七景视频已更新；旧遮罩版保留在gt_pairs/previous_masked。

现有GPU计时、模型输出、权重和逐帧指标均未改。旧summary字段GT_valid_roi实际指metric_roi_tlhw，应按评估区域理解。完整GT显示不扩大独立测试指标范围。新GT源在原评估区域与此前保存的同帧GT像素一致；780帧已完整重拼，不重新推理或训练。
