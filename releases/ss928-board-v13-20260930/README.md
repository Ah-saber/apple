## 同权重图：保留画质的优先对照

`onnx/equivalent/` 保留原日间稳帧、轻/中、重/C32 三套权重。参考双线性采样固定为两轴 Gather 和权重运算；参考金字塔放大也作相同改写，保留 AveragePool/ReduceMean。RAW 四相位抽取改为固定卷积，输出沿用已验证的 32 行分组铺排。图中无 GridSample、Resize，ONNX 检查通过；Gather 在实际 SDK 中的解析与归属待测。

五类分别连续核对 120 帧，FP32 改写相对原源模型最大差为 0.000214 灰度。C32 采样坐标保留原先 GPU 运算次序，随机双线性控制最大误差约 1.8×10⁻⁷。五类各一张完整 ONNX 经 ONNX Runtime 的 CPU 后端运行，相对同精度 PyTorch GPU 最大差为 0.000626 灰度。两项误差的后端和比较对象不同，记录分别保存。

FP16 会引入数值代价：600 帧中，日间相对 FP32 最大差为 1.114 灰度，天气各类约 0.398～0.443。实际 FP16 ONNX CPU 对 FP16 PyTorch GPU 的固定帧最大差为 0.625；上述数据均未经过 SDK 量化。

日间原有画质备选训练时使用重复末帧，故可将首层九通道权重求和，输入缩为一帧。`day_current_folded_*` 严格保留该备选的语义，120 帧最大差 0.000550 灰度；完整 FP32 ONNX 实际运行控制最大差 0.000504。日间稳帧九帧模型仍保留真实历史输入。

每类提供 FP32/FP16 的完整浮点输出、相位诊断输出和完整字节输出。相位图用于定位问题，速度成绩须来自完整输出图。字节图需要先做 `cast_probe/` 的板端逐值转换检查，再比较同帧完整输出和 Report；目前没有字节图性能结论。

## 天气四分之一网格：计算量缩减与画质代价

新模型使用步长 4 的九帧入口，在 256×320 网格学习 16 个空间相位，再恢复原 RAW 网格并作三倍显示复制。参考贡献放在主体卷积前；训练 20,000 步，另从该权重续训 8,000 步加强时序约束。两组候选均保留，权重按验证集选择。

天气主学习卷积约 0.803G 次乘加，原半网格约 2.454G，减少约 67%。此统计不包含参考支路和完整输出铺排。下表是同场景、同测试区域去除 3 像素边框后的 12 帧平均 PSNR（峰值信噪比，越高表示该像素误差指标越小）。

| 场景 | 原半网格，dB | 20k 候选，dB | 时序续训候选，dB |
| --- | ---: | ---: | ---: |
| 轻度 | 34.3049 | 33.6847 | 33.5891 |
| 中度 | 33.7914 | 33.1103 | 32.8751 |
| 重度 | 30.3357 | 30.1597 | 30.1630 |
| C32 | 23.7082 | 23.8772 | 23.7799 |

完整 120 帧中的原版→时序续训版：

| 场景 | 静态残差相邻帧变化，灰度 | 运动响应比 | 弱结构误差，灰度 |
| --- | --- | --- | --- |
| 轻度 | 0.892 → 1.055 | 0.468 → 0.518 | 1.282 → 1.411 |
| 中度 | 0.884 → 1.041 | 0.475 → 0.523 | 1.283 → 1.407 |
| 重度 | 1.506 → 1.756 | 0.532 → 0.651 | 1.754 → 2.026 |
| C32 | 1.624 → 1.811 | 0.703 → 0.815 | 1.983 → 2.158 |

指标定义与逐帧结果见 `runtime/run_compact.py` 和 `records/*/evaluation.json`。静态残差变化仍含模型误差，不能单独当作噪声量；运动响应更高也不能单独证明细节正确。续训降低了 20k 候选的部分波动，但未恢复原半网格的静态与弱结构指标。C32 大范围亮度误差仍存在。

两版新日间四分之一网格候选测试 PSNR 为 22.889/22.713 dB，原版为 25.499；运动响应从 0.334 降至 0.115/0.103，已排除，权重、日志和视频放在相应记录中供追溯。

RTX 5090 GPU1 同一协议测完整图：FP16、禁用 TF32、关闭 CUDA 图、torch.compile 默认模式，30 次预热、300 次 CUDA 事件计时。天气时序续训候选均值 0.321～0.343 ms，同权重改写半网格 0.324～0.334 ms，原半网格 0.299～0.312 ms。**GPU 未显示提速，NPU 收益待完整图实测。**详见 `records/final_temporal.json`。20k 候选结构相同，新增导出与数值控制，未重复测速。

## 两类夜间及数据边界

普通夜间保留 v0.12 的 `reference_after12`，特殊夜间保留 `lowref_k5`，本轮未重训或替换夜间权重。完整原图拷贝在 `onnx/night_preserved/`，原版本及既有整图视频继续保存在同分支的 `ss928-night-nine-v12-layout-20260929` 发布目录。两个完整图已使用本轮真实输入在 ONNX Runtime CPU 后端运行，对源 FP16 GPU 最大差分别为 0.500/0.375 灰度。

夜间采用原夜间数据源码，特殊夜间沿用共享 RAW 校正和全 RAW 参考，标签仅在原允许区域评分。同一视频空间留出的证据范围保持不变，不能据此宣称新视频泛化。普通夜间图 RAW 输入为 FP16、参考输入为 FP32；特殊夜间原图的两输入声明为 FP32，内部仍含半精度运算。按图内声明生成输入。

七类各 4 份训练校准和 12 份测试输入，共 28/84 份。所有训练校准使用九个不同的历史帧，不使用 GT 生成校准输入。测试首帧按原因果规则重复可用首帧；历史帧号在记录中明确列出。数据包同时保存归一化参数、模型输入、原始 uint16、实际参考缩略图、GT 无损 PNG 和源参考输出。五类逐层参考同时有 FP32/FP16；夜间保存源 FP16 逐层参考。

本轮始终沿用既有训练/验证/测试划分。验证集选权重，研发过程中多次观察了原测试结果，故该测试属于研发对照。所有视频保留完整画幅，四栏为已校正 RAW、GT、原半网格、候选。新视频十段均为 5120×1080、120 帧、12 帧/秒；该显示帧率不代表推理速度。逐帧指标已计算，人工抽查了日间、轻度及 C32 第 60 帧，未逐帧人工观看所有视频。

原网格恢复后的三倍输出是最近邻复制。当前结果不提供独立学习得到的三倍高分辨率细节。
